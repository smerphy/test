# Quickstart — gate an Anthropic agent in 5 minutes

## 1. Install

```bash
pip install praetor anthropic
```

## 2. Write a policy

Save as `policy.yaml`:

```yaml
policies:
  - id: allow-public-https
    effect: allow
    when:
      op: and
      clauses:
        - {op: eq, path: tool.name, value: http.get}
        - {op: matches, path: tool.arguments.url, pattern: '^https://'}
    reason: outbound https is on the allowlist

  - id: redact-tokens
    effect: transform
    when:
      op: matches
      path: tool.arguments.url
      pattern: 'token='
    reason: redact tokens before egress
    transform:
      url: '<redacted>'

  - id: deny-internal
    effect: deny
    when:
      op: matches
      path: tool.arguments.url
      pattern: '\.internal($|/)'
    reason: agents must not reach internal hostnames
```

## 3. Wrap your agent

```python
from anthropic import Anthropic
from praetor import PraetorClient, JsonlAuditSink
from praetor.middleware.anthropic import gate_response

client = Anthropic()
praetor = PraetorClient(
    bundle_path="policy.yaml",
    audit_sink=JsonlAuditSink("audit.jsonl"),
    default_agent_id="research-bot",
)

response = client.messages.create(
    model="claude-opus-4-7",
    max_tokens=1024,
    tools=[{"name": "http.get", "description": "Fetch a URL",
            "input_schema": {"type": "object", "properties": {"url": {"type": "string"}}}}],
    messages=[{"role": "user", "content": "Summarize https://example.com"}],
)

# Every tool_use block in the response is evaluated against the policy
# bundle. Allowed blocks pass through; transformed blocks have their
# arguments rewritten; denied blocks are replaced with a sentinel input
# so the model can re-plan on the next turn.
gated = gate_response(response, client=praetor, session_id="demo-1")
```

## 4. Verify the audit chain

```bash
python -c "from praetor import verify_chain; print(verify_chain('audit.jsonl'))"
```

Prints the number of verified events. Raises `AuditError` on the first
broken link or tampered hash.
